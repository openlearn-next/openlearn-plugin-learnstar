# OpenLearn 与学宠星球 (LearnStar Planet) 对接配置指南

本指南指导教师与学校管理员如何配置和使用 **LearnStar Planet 互通插件**，实现课堂教学与学宠习惯养成的全流程闭环。

---

## 一、互通模式选择

学宠星球互通插件支持两种运行模式：

### 模式 1：班级码轻量模式（推荐各班独立大屏）
- **适用场景**：上课老师直接使用各班的班级码；
- **配置步骤**：
  1. 登录学宠星球教师端或管理员端，获取当前班级的 **6 位大屏班级码**（例如 `A8K92F`）；
  2. 在 OpenLearn 插件设置中，认证模式选择 **班级码轻量模式**；
  3. 填入默认班级码并保存；
  4. 系统即可通过快速加分接口直接下发积分，并在点击“打开教室大屏”时直达 `/classroom`。

### 模式 2：教师凭据全功能模式（推荐系统级自动同步）
- **适用场景**：学校统一部署、希望 OpenLearn 班级名单与学宠星球自动对齐；
- **配置步骤**：
  1. 在学宠星球中创建或使用教师账号；
  2. 认证模式选择 **教师凭据高级模式**；
  3. 填入学宠教师用户名与密码；
  4. 插件将自动通过 Sanctum 获取令牌，支持拉取该教师名下的所有班级列表并批量导入/同步学生花名册。

---

## 二、课堂行为与学宠成长自动联动

插件在 OpenLearn 运行时监听以下核心事件：

1. **作业批改完成 (`assignment.graded`)**：
   - 教师在 OpenLearn 中完成作业批改并打分时，插件自动捕获事件；
   - 依据配置的**换算比例**（默认 1:1），自动调用学宠星球的加分接口；
   - 学生对应的学宠获得成长值，并在达成阶梯门槛时自动触发进化！
2. **课堂签到到课 (`attendance.recorded`)**：
   - 学生完成课堂签到时，系统自动奖励到课成长分（默认 +5 分），激励学生准时出勤；
3. **手动激励派发**：
   - 教师可在插件面板或课堂白板中随时进行实时加分激励，直接将积分写入学宠星球数据库。

## 四、常见问题排查

1. **测试连接提示无法访问**：
   - 确认学宠星球后端服务已正常启动（默认端口通常为 `8000` 或 Docker 部署指定端口）；
   - 确认防火墙已放行 `/api/v1/*` 端口。
2. **作业打分后学宠星球未收到积分**：
   - 进入插件的【📜 实时同步流水】选项卡查看是否有失败错误日志；
   - 检查 OpenLearn 班级与学宠星球班级是否已完成对应映射，或学生学号是否匹配。
